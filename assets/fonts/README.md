# Bundled brand fonts

Static TTFs of the three Renball typefaces, so slides (PowerPoint) and X images
(matplotlib) render identically on any machine. Web pages keep loading the same
families from Google Fonts. All three are licensed under the SIL Open Font
License 1.1 — the licence text sits next to each family (`OFL.txt`); none
declares a Reserved Font Name.

| Folder | Files | Source | Version |
|---|---|---|---|
| `instrument-serif/` | Regular, Italic | [google/fonts `ofl/instrumentserif`](https://github.com/google/fonts/tree/main/ofl/instrumentserif) — official static files | 1.000 |
| `dm-sans/` | Regular, Italic, Medium, Medium Italic, Bold, Bold Italic | static instances of the official variable fonts in [google/fonts `ofl/dmsans`](https://github.com/google/fonts/tree/main/ofl/dmsans), generated by `build_dm_sans_static.py` at `opsz=14` | 4.004 |
| `jetbrains-mono/` | Regular, Italic, Medium, Bold | [JetBrains/JetBrainsMono `fonts/ttf`](https://github.com/JetBrains/JetBrainsMono/tree/master/fonts/ttf) — official static files | 2.305 |

## Who uses them

- `assets/social/renball_chart_style.py` registers this folder **first**, so X images never depend on what's installed.
- PowerPoint only sees fonts installed in Windows. On CK's machine (2026-10-23) these are installed per-user: Instrument Serif Regular + Italic and the static DM Sans set; JetBrains Mono is the previously installed variable font (v2.211), which PowerPoint renders correctly but files under the name "Calibri" in exported PDFs.
- Check what's installed: `.venv/Scripts/python.exe assets/build/renball_pdf.py --check-fonts`

## Installing on a new machine (per-user, no admin)

Right-click each `.ttf` → **Install** (Windows installs for the current user), then restart PowerPoint.
